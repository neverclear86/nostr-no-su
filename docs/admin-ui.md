# Admin UI

## クライアントの接続

- `nostrconnect://` で接続したクライアントは、**セッションごとのリレー**に対して
  `connect` の応答を受け取り署名できます。  
- そのリレーは DB の `relays` テーブルに登録されず、接続が切れたら破棄されます。

## バンカーリレー

- バンカーは **専用接続（リレーごと）** ではなく、各クライアントの
  セッションに対して個別に作成されます。  
- すべての署名者の `#p` を購読し、AUTH を送信する **基本のバンカーリレー** は
  依然として存在しますが、`nostrconnect://` の URI はここに登録されません。
