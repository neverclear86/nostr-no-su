# Design Decisions

## バンカーは専用接続（リレーごと）

- `nostrconnect://` で接続したクライアントは、**セッションごとのリレー**を使用します。  
- そのリレーは DB に永続化されず、接続が終了すると破棄されます。  
- これにより、クライアントごとに独立した署名環境を提供し、他のクライアントに影響を与えません。

## クライアントのリレーに届く情報

- クライアントの署名者の `#p` を購読し、AUTH を送信します。  
- `connect` の応答はそのセッションのリレーを通じて送られ、E2E で署名できます。

## 基本のバンカーリレーに届く情報

- すべての署名者の `#p` を購読し、AUTH を送信します。  
- これは全体の管理用リレーであり、`nostrconnect://` の URI は登録されません。
